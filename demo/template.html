Read those columns for what they are. The first two measure the extractor, using the paper’s own lexicon as the instrument, so a “catch rate” derived from them restates the measurement rather than validating the gate. The independent number is the last column: zero false positives in twenty opportunities on genuinely confident memories. Hedge-stripping came nowhere near the 100% the source paper reports — on this corpus these models usually keep “reportedly” unprompted. n is small and shrinks as abstention rises; treat the rates as directional.

The seven checks

Each one cites the result it comes from. A check that cannot apply reports N/A — never PASS.

BRITTLE REJECT

A derived conclusion survives but the values it was computed from are gone. “The total was $55”, with no line items.

Reclaim, Sec. 4 — source-token test

TRUNCATED REJECT

What was retained no longer recomputes the stored total, and no “k of N” completeness tag admits it.

Reclaim, Sec. 7 — recompute certificate

MANUFACTURED_CONFIDENCE REWRITE

The source hedged and the memory does not. Evidential hedges (“reportedly”, “rumor”) are flagged loudest — they are the near-universal blind spot.

Manufactured Confidence, App. E — dehedged()

LAUNDERED REWRITE

Attribution disappears between source and store, so hearsay is filed as established fact.

Manufactured Confidence, App. E — laundering metric

POLARITY_CHANGED REJECT

The source denied it and the memory asserts it. Worse than laundering: laundering keeps the fact and drops the stance, a flip stores the opposite fact.

Factwash — closed-class negation, 0.91 F1 on held-out external text

CONDITION_DROPPED REWRITE

“Alice can approve it if Bob is absent” stored without the condition, turning a conditional permission into a standing one.

Factwash — closed-class conditionals

TEMPORAL_SCOPE_DROPPED WARN

The source dated the claim and the memory stores it undated, so it reads as current later. A warning, not a block: a dropped date is stale-risky, not wrong.

Factwash — bounded time expressions

The gate running above is a direct port of the Python package. It was cross-checked against factwash.check() on 157 pairs — every test fixture plus every real extraction and rewrite from the paid runs — with zero disagreements. It is still a port: the shipping gate is the Python one.

Known limits, stated rather than hidden: the lexicons are English-only and substring-matched, so record fires on “system of record” and note on “quick note before I forget”. That accounts for the single false positive in the package’s calibration corpus. Checks are claim-local rather than whole-memory, because real extractor preamble (“I’ve noted the following”) otherwise shields the bare claim beneath it.
